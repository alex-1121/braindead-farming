# Braindead Farming

No more need for planning your farming runs. Braindead Farming does it for you, just follow the instructions.

## Structure
- `src/main/java/com/braindeadfarming/BraindeadFarmingPlugin.java` – plugin entrypoint.
- `src/main/java/com/braindeadfarming/BraindeadFarmingConfig.java` – plugin config.
- `src/main/resources/runelite-plugin.properties` – plugin-hub metadata.

## Build
Use the Gradle wrapper:

```bash
./gradlew build
```
